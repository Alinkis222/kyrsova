# Lapka

Сайт на FastAPI без Jinja2. HTML/CSS формируются напрямую, база данных предпочитает файл Access KyrsovaFA1.accdb, а если драйвер недоступен — автоматически работает SQLite fallback.

У каталозі можна відкрити сторінку кожного товару з описом, ціною, залишком і фотографією. Продавець може додавати, редагувати й видаляти товари в панелі, а також завантажувати фото JPEG, PNG, WebP або GIF (до 5 МБ). Товари, що вже присутні в замовленнях, видалити не можна; замість цього можна змінити їхній залишок.

Установка (выполняйте команды из папки `kyrsova`, где находится `main.py`):
```powershell
pip install -r requirements.txt
uvicorn main:app --reload
```
Откройте http://127.0.0.1:8000.
